Extra pump work
Watts above the clean-filter baseline — 0 means no extra work
Extra watts = actual power draw minus expected for a clean filter at that flow rate. Expected is the 10th-percentile W/GPH ratio per 200-GPH flow bucket across all history, so it adapts to each speed program independently. The line sits near 0 when clean, rises as the filter clogs — unaffected by speed-program switches that used to dominate the chart.
